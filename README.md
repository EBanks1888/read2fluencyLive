# Read2Fluency

A simple static website for language learners to browse graded readers by language, CEFR level, and genre.

## Features

- Language selection
- CEFR level filter
- Genre filter
- Book list with Amazon links

## Run locally

Open `index.html` in your browser, or use a local static server if you prefer:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
